Help & frequently asked questions

Getting started

PulseCount is a collection of customizable, simulated subscriber and view counters. Choose a layout, set a name and starting count, configure the gains, and use it for entertainment, design, or streaming projects.

Top 50

Saves and troubleshooting

Open Import & Export Data in the counter settings and export a JSON save. You can import that file later in this browser or on another device.
Browser data can be cleared by privacy tools, private browsing, or a manual reset. Keep an exported backup of important configurations. If a database upgrade is blocked, close other PulseCount tabs and reload.
Open the main page and select “Reset local data” in the footer. Export anything you want to keep first; a full reset cannot be undone.
